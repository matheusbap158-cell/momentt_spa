# Momentt Spa (demo)

Landing page de demonstração, HTML único (`index.html`), sem dependências além das fontes do Google Fonts. Não publicada.

## Estrutura
- `index.html`: o site
- `Copy.txt`: texto da página
- `design-system-momentt-spa.md` / `.html`: design system
- `assets/`: logo (`logo.png`), marca da flor (`logo-flor.png`) e favicon
- `Logo/`, `Fotos/`, `Instagram/`, `Materiais pra Copy/`: materiais de origem

## Como visualizar
Na pasta da agência: `node "_ferramentas/preview-local.mjs" "4. Meus Clientes/2. Demos e propostas/momentt_spa"` e abrir o endereço mostrado.

## Pendências
Veja a ficha em `4. Meus Clientes/_Fichas/Momentt Spa.pdf`. O site mostra os itens `[A CONFIRMAR]` com borda tracejada.

## Antes de publicar
O `index.html` tem `<meta name="robots" content="noindex, nofollow">` para a demo não aparecer no Google. Remover essa linha ao publicar o site definitivo do cliente.
